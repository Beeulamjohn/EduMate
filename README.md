# EduMate – Education Management System

**Organization:** SciPy Technologies Pvt. Ltd.  
**Project Type:** Web-Based Education Management System  
**Document Version:** 2.0

## About the Project

EduMate is a web-based Education Management System developed using Python and Django for SciPy Technologies Pvt. Ltd.

The main purpose of this project is to simplify and manage educational activities through a centralized platform. It provides an organized interface for managing student admissions, course scheduling, fee collections, and examination applications.

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Font Awesome

## Developed Modules and Features

### 1. Admission Dashboard
- Enquiry Management
- Counselling Management
- Student Admission Registration
- Student Directory
- Admission Reports
- Admission Settings
- Student and Admission ID Management

### 2. Course & Batch Scheduling Dashboard
- Course Management
- Technical and Non-Technical Courses
- Batch Management
- Trainer Allocation
- Course and Batch Scheduling
- Batch Start and End Date Management
- Upcoming Sessions

### 3. Fee Collections & Billing Dashboard
- Fee Structure Management
- Installment Management
- Student Fee Collection
- Payment Management
- Invoice Generation
- Outstanding Fee Tracking
- Fee Reminders
- Payment Status Management

### 4. Exam Application Dashboard
- Diploma Examination Management
- Student Exam Applications
- Student Eligibility Verification
- Examination Registration
- Examination Fee Management
- Payment Verification
- Hall Ticket Management

## Project Objectives

- Simplify student admission processes.
- Manage courses and training batches.
- Organize student fee collections and payments.
- Manage examination applications and eligibility.
- Provide a centralized dashboard for educational administration.
